# agentsniff-common

Shared types and event structures for [AgentSniff](https://github.com/ThirdKeyAI/agentsniff) — the AI agent network scanner. This crate carries the no-std-friendly definitions that are used by both the `agentsniff` userspace binary and the optional eBPF probes.

You almost certainly want the [`agentsniff`](https://crates.io/crates/agentsniff) crate, not this one.
